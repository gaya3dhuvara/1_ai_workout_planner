## How to Run the Project

1. **Clone / open the project folder** (`c:\Learnings\cohort\assign_1`).
2. **Install the required Python packages**:
   ```powershell
   pip install streamlit httpx python-dotenv
   ```
3. **Add your Groq credentials**:
   - Edit the generated `.env` file (or create one if missing) and set:
     ```text
     GROQ_API_KEY=your_groq_api_key_here
     GROQ_MODEL=llama3-70b-8192   # or any model you prefer
     ```
4. **Start the Streamlit app**:
   ```powershell
   streamlit run app.py
   ```
   This will open a browser window at `http://localhost:8501`.
5. **Use the UI**:
   - Fill in the fitness parameters.
   - Click **Generate Plan** (or **Regenerate** for a new variation).
   - The generated plan appears; you can swap individual exercises, or download the plan as a text or markdown file.
   - If the Groq API call fails, the app automatically displays a deterministic default plan generated by the bundled `default_plans.py` module.
